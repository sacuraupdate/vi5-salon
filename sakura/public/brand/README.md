## 注意

- ファイルが無い場合は**人物のシルエットや仮アイコンを一切表示しません**。
  HERO は桜紋・SAKURA・肩書だけのブランドビジュアルへ自動で切り替わり、レイアウトは崩れません。
- 代替イラスト・代替写真は自動生成しません。
- 桜は「日本らしさの補助」として使い、大量に散らしません。
  主役は 白・濃紺・朱赤・松葉色 です。
- 写真の上に大量の桜や文字は重ねません。桜の枝は必ず写真の背面に入ります。
